# Roadmap — discord-rpg

Структура для Trello: каждый `##` — отдельный список (колонка), каждая строка — отдельная карточка.
Теги в `[]` — Label по сервису: `Backend` (Symfony), `Activity` (React), `Bot` (discord.js), `Infra`, `GD` (game design).

## 📋 Game Design (Backlog)
- [GD] Описать классы персонажей и стартовый набор бит (минимум 3 класса)
- [GD] Спроектировать грани бит (удар/защита/действие) и их баланс
- [GD] Описать умения, активируемые через грань "действие"
- [GD] Формула сравнения комбинаций граней → урон/эффект
- [GD] Список стартового снаряжения и его модификаторов
- [GD] Экономика: цены снаряжения, награды XP/монеты за победу
- [GD] Система уровней и энергии (лимит боёв в сутки)
- [GD] 2-3 сценария периодических ивентов (нападение монстров)
- [GD] Формат турнира: брекет, расписание, награды
- [GD] Типы и награды недельных заданий

## ⚙️ Sprint 0 — Инфраструктура
- [Infra] Symfony skeleton + Docker (php-fpm, nginx, postgres)
- [Infra] React (Vite) проект под Discord Activity
- [Infra] Discord bot проект (discord.js) + структура
- [Infra] Регистрация приложения в Discord Developer Portal, включить Activities
- [Infra] HTTPS-туннель для разработки (Developer Tunnel/ngrok)
- [Infra] CI: lint + tests для backend и activity
- [Backend] Doctrine ORM + миграции
- [Infra] .env / секреты (Discord Client ID/Secret, DB)

## 🧑‍🚀 Sprint 1 — Аккаунты и персонажи
- [Backend] Сущность User (discord_id, OAuth-профиль)
- [Backend] Discord OAuth2 авторизация (code → token → profile)
- [Backend] Сущность Character (class, hp, energy, level, xp, coins)
- [Backend] Сущность CharacterClass со стартовым набором бит
- [Backend] API: создание персонажа (выбор класса)
- [Backend] API: получение профиля персонажа
- [Activity] Экран выбора класса персонажа
- [Activity] Экран профиля персонажа (HP/энергия/уровень)
- [Bot] Команда /profile — карточка персонажа в чате

## ⚔️ Sprint 2 — Боевая система (ядро)
- [Backend] Сущность Bit (2 стороны: удар/защита/действие)
- [Backend] Сущность Battle + BattleRound (лог боя)
- [Backend] Логика броска бит (случайная сторона каждой биты)
- [Backend] Сравнение комбинаций граней → расчёт урона/эффектов
- [Backend] API: создать бой (PvE против бота, базовая версия)
- [Backend] API: сделать ход в бою (бросок, применение эффекта)
- [Backend] Обработка грани "действие" (переворот биты соперника, умение)
- [Backend] Юнит-тесты боевой логики (граничные комбинации)
- [GD] Балансировка после первых тестовых боёв

## 🎮 Sprint 3 — Discord Activity (визуализация)
- [Activity] Интеграция Discord Embedded App SDK (авторизация внутри Activity)
- [Activity] Анимация броска бит (монетка/переворот)
- [Activity] Экран арены: HP-бары игрока и противника
- [Activity] UI выбора действия/умения между раундами
- [Activity] Поллинг состояния боя с backend (оптимистичный UI)
- [Activity] Экран результата боя (победа/поражение, награды)
- [Infra] Деплой Activity на HTTPS-хостинг (staging)

## 🤖 Sprint 4 — Discord Bot интеграция
- [Bot] Команда запуска Activity в голосовом канале
- [Bot] Команда /duel @user — вызов на PvP-дуэль
- [Bot] Подтверждение дуэли кнопками
- [Bot] Команда /pve — бой против бота (с проверкой энергии)
- [Backend] API: проверка и списание энергии за PvE-бой
- [Bot] Уведомление о результате боя в текстовый канал

## 🛒 Sprint 5 — Экономика и снаряжение
- [Backend] Сущность Equipment (модификатор бит/HP, цена)
- [Backend] API: список снаряжения (магазин)
- [Backend] API: покупка снаряжения (списание монет)
- [Backend] Применение бонусов снаряжения в бою
- [Activity] Экран магазина
- [Activity] Экран инвентаря персонажа
- [Bot] Команда /shop — краткий список + ссылка на Activity

## 👹 Sprint 6 — PvE-ивенты
- [Backend] Сущность Event (тип, время начала/окончания, параметры)
- [Backend] API: запуск ивента "нападение монстров" (админ-команда)
- [Backend] Логика участия всех online-игроков в ивенте
- [Bot] Рассылка уведомления о старте ивента в канал
- [Bot] Команда участия в ивенте
- [Activity] Экран ивент-боя (переиспользует арену)
- [Backend] Начисление наград за участие/победу в ивенте

## 🏆 Sprint 7 — Турниры и недельные задания
- [Backend] Сущность Tournament + брекет-логика
- [Backend] API: регистрация на турнир
- [Backend] API: автогенерация пар и прогресс брекета
- [Bot] Команды турнира (/tournament join, /tournament bracket)
- [Backend] Сущность WeeklyQuest + прогресс выполнения
- [Backend] Cron/scheduler: генерация новых недельных заданий
- [Activity] Экран турнирной сетки
- [Activity] Экран недельных заданий

## ✨ Polish / Post-MVP

- [Activity] Полировка анимаций и звука
- [Backend] Логирование/аналитика боёв (для баланса)
- [Infra] Мониторинг и алерты (ошибки backend, аптайм Activity)
- [Bot] Лидерборд сервера (/leaderboard)
